# 🍋 Little Lemon Booking App

## 📌 Overview

The **Little Lemon Booking App** is a responsive web application designed to simplify table reservations for customers.  
Users can easily book tables through an interactive form with proper validation and accessibility support.

This project focuses on creating a seamless booking experience with a clean and user-friendly interface.

---

## 🚀 Features

✅ Table booking form  
✅ Form validation  
✅ Responsive design  
✅ Accessibility support  
✅ User-friendly interface  
✅ Smooth booking experience

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
